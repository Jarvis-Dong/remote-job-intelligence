# One-time publication

The repository is intentionally publishable without credentials. The local
Actor has not been sent to Apify from this checkout.

1. Sign in to Apify through its official Console or CLI. Never put an API token
   in this repository or in chat.
2. From this directory run `npx apify-cli actors push --wait-for-finish 600`.
3. In the Apify Console, review the four source attribution requirements and
   set a conservative pay-per-event price. Run a small public test with the
   default filters before enabling Store visibility.
4. Record a payout only after it is settled in the Apify account. Until then,
   the experiment ledger remains `¥0`.

There is no scheduled job, login automation, application submission, or proxy
rotation in this project.
